# **WOG Authentication UI**

Небольшая форма авторизации в фирменном стиле **WOG**, выполненная на HTML и CSS.  
Поддерживает анимацию плавающих label, встроенную HTML-валидацию, success/error-состояния, shake-эффект и современный адаптивный интерфейс.

---

## **Особенности**

- **Плавающие подписи** с плавной анимацией  
- **HTML-валидация** с визуальной success/error-подсветкой  
- **Shake-анимация** при неверном вводе  
- **Фирменные цвета WOG** (green / lime)  
- **Адаптивный дизайн**, удобный для мобильных устройств  
- **BEM-классы** и структурированный CSS
